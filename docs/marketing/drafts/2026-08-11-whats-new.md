## Draft: r/mcp / r/ClaudeAI post

**Title:** canvas-lms-mcp now ships as a one-command Claude Code plugin, plus course-copy and Scheduler tools

---

Since the last update, [canvas-lms-mcp](https://github.com/bruchris/canvas-lms-mcp) added a few things worth a look if you're building Canvas-connected agents.

**One-click Claude Code plugin.** `/plugin marketplace add bruchris/canvas-lms-mcp` then `/plugin install canvas-lms-mcp` installs the MCP server *and* all 16 bundled Agent Skills in one step, versioned through Claude Code's plugin manager. On enable it prompts for your Canvas token/base URL (and the optional FERPA pseudonymization settings) instead of hand-editing a config file. Two new skills shipped alongside it: `canvas-accessibility-sweep` (pre-launch WCAG + broken-link sweep with a prioritized fix list) and `canvas-office-hours` (create/publish/manage Scheduler sign-up slots and see who reserved).

**Content migrations.** `create_content_migration` kicks off a course copy, Common Cartridge import, zip import, QTI conversion, or Moodle conversion; `get_content_migration` / `list_migration_issues` track progress and surface any todos/warnings/errors Canvas reports back. `get_migration_selective_data` and `get_migration_asset_id_mapping` round it out for selective imports and resolving old→new content references.

**Appointment groups (Canvas Scheduler).** Full CRUD on Scheduler sign-up slots — `create_appointment_group`, `update_appointment_group` (including publish + adding new time slots), `list_appointment_groups`, plus `list_appointment_group_users` / `_groups` to see who's booked and `next_appointment` for "what's my next slot" lookups.

**Tool titles + a privacy policy**, added for readiness against the emerging Connectors-directory review bar (human-readable titles on every tool, plus a published privacy policy).

Current count: **163 tools across 41 domains** on a default install (117 read-only, 46 write) — courses, assignments, submissions, gradebook history, rubrics, quizzes, New Quizzes, files, users, groups, enrollments, discussions, modules, pages, calendar, conversations, peer reviews, accounts, analytics, outcomes, grading standards, grade projection, link audit, accessibility audit, content exports, content migrations, quiz accommodations, appointment groups, and more.

## Optional add-on paragraph (hold until v1.27.0 is published)

**Students can now submit their own work through the agent — opt-in only.** Two new write tools, `upload_submission_file` and `submit_assignment`, let a student-role agent turn in `online_text_entry`, `online_url`, or `online_upload` submissions. They're **off by default** — you have to set `CANVAS_ENABLE_ASSIGNMENT_SUBMISSION=true` (or `--enable-assignment-submission`) to register them at all, because Canvas submissions are irreversible and can consume a limited attempt. Both tools carry `destructiveHint: true`, so a compliant MCP host will show the user exactly what's about to be submitted and ask for confirmation first. Hidden entirely under teacher/admin role filtering, since they only make sense for a student's own enrollment.
